# Фаза — это скилл, а не объявленная стадия

Движок не заводит собственную модель конвейера: фаза начинается ровно тогда, когда загружается `SKILL.md`, и называется именем скилла. Альтернатива — объявить стадии (`grill → spec → tickets → implement → review`) и привязывать к ним скиллы — дала бы место для составных скиллов, но потребовала бы второй сущности и ручного маппинга, который расходится со скиллами при каждом их обновлении. Граф переходов уже размечен в самих скиллах фразами вида «call the Skill tool with "tdd"», то есть существует без нашего участия.

## Последствия

`implement` со своими пятью шагами остаётся одной фазой. Шаги внутри неё держатся не вложенной машиной состояний, а гейтом `visited`: фаза не закрывается, пока в сессии не запускался `code-review`.
