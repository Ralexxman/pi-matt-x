# Человеческое подтверждение — это новое сообщение пользователя

Скиллы требуют «дождись подтверждения» в раундах гриля, на швах спеки и в quiz по тикетам. Расширение не заводит для этого свой диалог: пока гейт открыт, мутирующие возможности заблокированы, а закрывает его любое следующее сообщение пользователя. Альтернатива с `ctx.ui.confirm` добавляет второй вопрос поверх вопроса скилла на каждом переходе и полностью не работает в json/print/RPC. Альтернатива с чтением результата `ask_user_question` небезопасна: набор вариантов формулирует сама модель, то есть она же и решает, что считать подтверждением.

## Последствия

«А что если» и «переспроси» тоже закрывают гейт. Это принятая цена: гейт держит от проскока в действие, а не от недопонимания. В режимах без UI поведение то же самое — гейт просто не открывается сам.
